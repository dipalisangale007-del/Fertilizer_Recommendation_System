# Fertilizer Recommendation System 

## Description
A machine learning-based system that recommends fertilizers based on soil nutrients, crop type, and environmental conditions.

## Features
- Predicts fertilizer using ML model
- Uses Flask for web interface
- Uses real-time weather API

## Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- HTML/CSS

## How to Run
1. Install dependencies:
   pip install flask pandas scikit-learn joblib requests

2. Run:
   python App1.py

3. Open browser:
   http://127.0.0.1:5000
